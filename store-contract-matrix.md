## Intentional semantic boundaries

1. **Transition identity.** Native work names explicit transition/operation IDs and root membership. React's userland implementation discovers `startTransition` through an adapter and the fork uses lanes/actions. Observable action order and visibility are comparable; lane entanglement, scheduling priority, and React render retries are not native store requirements.
2. **Root projection.** Native roots are explicit and may independently commit. React userland's reader handles and the fork's per-root lane projections are analogous only at the visibility boundary. Do not require global all-root atomicity unless the native call requested a commit group.
3. **Promises.** Native store values remain ordinary, including thenables. Unwrapping and Suspense are explicit compiler/runtime resource operations. React's `use(store)` followed by `use(promise)` and userland's fulfilled-handle mechanism do not establish native boundary parity.
4. **Stale work.** Native's specified action-log behavior retains dispatched actions when work cancels/detaches; cancellation releases ownership/holds, not domain actions. Userland React tests may characterize a reader lifecycle, but they do not define native compensation or cancellation semantics.

## Native async acceptance checkpoint — 2026-10-12

The three tests in `src/native_late_reader_matrix_test.ts` and the actual authored-module fixture `compiler/native_promise_store_race_execution_test.mjs` close the named late-reader and combined Promise/source races above. The full checkpoint passes 363 Deno tests, 22 Rust tests and 20 verification commands. No kernel changes were required for this slice.

The finite native acceptance corpus is sufficient to proceed to public host contracts. Retain the projection oracle, scope, queue, generation-lease and compiled race cases as regression gates. Explicitly scoped pending Promise updates allow urgent independent edits to keep using the committed projection; this does not promise that any urgent unresolved Promise replacement stays interactive.

Remaining evidence limits: upstream suites have not run against this implementation; direct native-versus-React differential traces remain distinct work. Browser composition uses simulated events, not OS IME. These correctness checks establish no performance, size or cross-thread execution result. With a manually controlled root scheduler, current store projections can advance before the last rendered UI; a store getter is not an immutable committed UI snapshot.
