Async invalidation and retry: React vs compiled runtime

React uses React Compiler, a Suspense resource cache, and a transition. The compiled runtime uses the OXC task DAG, same-root urgent state, and either full restart or reuse of completed tasks outside the changed-input closure.

Each trial starts a slow stale search, changes the query while it is pending, then measures query-update to fresh DOM commit. React keeps the old result visible and transitions only to the latest query; the runtime starts the stale task and invalidates it when ECS state changes. The independent catalog result is cached by React and reused by the runtime's selective policy. Mount, layout, paint, and frame presentation are excluded.
