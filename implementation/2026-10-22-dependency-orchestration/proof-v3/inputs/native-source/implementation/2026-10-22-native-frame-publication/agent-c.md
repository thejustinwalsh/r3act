# Packet C: actual compiled frame fixture

Owned file: `compiler/compiled_native_frame_publication_test.mjs`. This is source-only implementation; no test, build, benchmark or server was run by this implementation agent.

Primary source review corrected the outer `storeRecord` import and uses a later timestamp for the post-retirement advance, so that assertion checks retirement rather than monotonic-time rejection.

The fixture replaces the private, caller-owned clock/flush/hidden-marker readiness proof with public `createNativeFrameLoop` over an actual Rust/OXC transformed TSX module. Its compiled DOM and Three motion components read the same Store and retain children. The fixture checks emitted closed Store programs and owned execution metadata, then mounts real DOM-memory and Three roots. It uses the existing root publication versions and snapshots as acceptance authority.

The selected frame has an explicit DOM/Three Store group. The host callback observes old managed snapshots during the first writer, checks Three has not written yet, and checks draw has not run. Draw checks both host values after publication. A fork retains independent Store history; unrelated DOM and resource roots progress while the controller is active. A host-time newer Store dispatch remains pending for the next acceptance. A second writer starts a frame while its host is busy; the group settles after that writer, and an intervening local root publication forces currentness validation before the delayed draw. The original frame time and one update call are asserted. Retained child/event identity and Three geometry/material lifetime are checked. A partial host writer failure must return a failed frame with no draw, no accepted-history advance and a quarantined domain. Semantic-plan invalidation must retire the participants and prevent another draw. Cleanup checks exact Three resource disposal and empty roots.

The measured budget for this packet is semantic correctness; there is no measured time saving or cold/memory budget. Falsifiers are any early draw, torn accepted group, consumed newer action, blocked unrelated work, changed retained identity, replay after partial failure, draw after code retirement or leaked Three resource. The fixture does not prove physical presentation, a hard deadline, React parity or independent-device performance.

Verification handoff to Luna, after primary freezes the combined source and adds this fixture to the native runner: use the repository's consolidated native gate with the locked `COMPILER_SPIKE_BINARY`; its expected fixture artifact is `.cache/compiled-native-frame-publication-*/{provenance,result}.json`. Do not rebuild the compiler for this fixture. The fixture itself can be invoked with the same installed Node/TypeScript loader command used by the runner for neighboring `compiled_*.mjs` tests.
