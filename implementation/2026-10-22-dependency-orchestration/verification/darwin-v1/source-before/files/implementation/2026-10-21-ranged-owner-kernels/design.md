## Named source work and replacement

VDOMSnapshotRoot's heterogeneous numeric executor preserves contiguous original-order runs. For every run it currently allocates runInputIndices, runSinkIds, runValues and runRows, creates a changedSlots subarray view, invokes executeCut, validates run-relative outputs, then copies/remaps each output into existing whole-cut staging arrays. The installed canvas workload alternates Position/Rotation per owner, so runs can be one row wide. This is actual source work, not a measured phase share.

Extend the compiler/core owner-kernel ABI to execute a range of the existing whole-cut input and output buffers. New compiled programs use schema 4 (ordinary numeric owner) or 5 (retained-child admission), replacing newly emitted schema 2/3. New cores retain 2/3 compatibility through the existing isolated legacy adapter; old cores reject new schemas. Sink descriptor/state-layout schemas and module revision authority do not change. No new runtime plan selector, mutable identity/version registry, cache, storage layout or traversal family is added.

executeCut keeps its existing six parameters and appends inputStart=0, outputStart=0. changeCount remains the number of inputs in the range; rowStates and changedSlots are whole-cut buffers. For local index i, changeIndex=inputStart+i is the absolute input/staged input identity. Outputs append at outputStart; the return value is the number appended, not the absolute end. Uniform calls with omitted offsets retain the old shape. Retained-child metadata is required exactly for schema 3/5.

The ranged runtime branch passes existing whole-cut buffers, original run start/length and output prefix directly. It retires run-local arrays, subarray view, row copy and triple-copy/remap only for range-aware programs. It keeps capacity, integer/range, sentinel, actual-written-value, sink-mask, primitive-value, cancellation and final live validation before host writes. Do not infer purity or private ownership from function shape/schema alone; opaque callbacks retain the existing conservative contracts. Compatibility is an ABI distinction, not permission to skip live checks.

## Holes, lifetime and failure

A reused value buffer must distinguish an explicitly staged undefined from an unwritten slot. Truncate its future suffix at outputStart before a ranged call (or use another reviewed nonallocating sentinel protocol); validate Object.hasOwn for every claimed value along with out-of-range index sentinels. Reject malformed output counts and input indices outside the current run before host application. Do not expose an unwritten stale value from the previous frame. Clear the complete reusable value payload on every success/failure/cancellation so a malformed ranged kernel cannot retain objects beyond a claimed output prefix. Keep typed-buffer bounds and existing cleanup behavior; never mask the original host/kernel exception.

Per-row seenMask deduplication, input capture, sink equality (signed zero/NaN), staging/host order, all source/writer/owner liveness checks, exact acknowledgements, newer reentrant actions, per-root accepted history/forks, partial-host quarantine, resources and generic fallback remain. No whole-tree/root guard is removed. Ranges do not fuse across owners, reorder independent programs or establish workers/parallelism.
