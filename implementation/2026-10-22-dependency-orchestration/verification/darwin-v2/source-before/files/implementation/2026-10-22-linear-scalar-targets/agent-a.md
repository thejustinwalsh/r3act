# Packet A handoff — linear scalar target selection

Owned files: `src/vdom_snapshot_runtime.ts`, `src/vdom_mounted_scalar_plan_test.ts`, this note. No gates or benchmarks were run by Packet A.

The replaced mechanism is the per-recipe peer-membership proof: `ScalarPlanFields.members`, per-successor peer `WeakRef` arrays, repeated warm-hint peer comparisons/dereferences, and reconstruction of a candidate's first member snapshot from recipe peers are deleted. A recipe now retains only its own node, accepted VNode, handle, prop layout and retained children.

For each distinct selected raw key, the existing candidate-local `buckets` map snapshots current `#nodesByKey` members once. The first owner-qualified region builds one owner-to-node map from that snapshot; duplicate owners map to `null`. Each region resolves a unique current node before reading a hint. A genuine hint reuses layout only if it names that exact selected node and its current VNode, handle, root, key, tag, owner, scoped source, children and output-name order match. Missing, foreign, forged, proxied, wrong-owner or stale hints fall through to cold normalization on the selected node. This is O(B + T + P + C) target preparation at fixed arity; the measured time budget remains unknown.

The candidate still stores its exact bucket-member footprint. Existing admission, post-host and private-current checks, per-changed-write writer/placement/current checks, accepted journal, applying/saved snapshot behavior, immutable accepted VNode publication, generic fallback and partial-host quarantine remain untouched. No persistent registry, generation proof, host writer or public interface was added. Profiling callbacks remain at the existing successful preparation boundary; no callback occurs inside snapshot, index or target loops. The four counters `store.scalar-target.bucket-builds`, `store.scalar-target.member-visits`, `store.scalar-target.owner-index-visits` and `store.scalar-target.owner-lookups` count the actual local loops/lookups and are disabled when no profiling callback is installed. They are loop counts, not elapsed time.

Authored bounded regressions: `mounted scalar target selection visits N same-key owners once` for N=1/32/256/1024 (cold plus two warm frames, reversed owner order, retained children/constant/output identity and exact per-preparation counts); `scalar target snapshots distinct selected keys once` (unequal buckets, singleton marker, untargeted peers); `duplicate same-key owner declines cold and hinted selection`; `wrong-owner scalar hint cannot redirect a current target`; `same-key peer churn invalidates prepared footprint and rebinds cold`; and `scalar writer replacement inside first write stops the next target`. Existing forged/proxied/foreign/stale-hint, signed-zero, applying/saved snapshot, second-writer throw and discarded getter tests remain.
