# One boundary-reveal diagnostic

Status: **ONE DESCRIPTIVE PAIR COMPLETED; see [gate results](../verification/gate-results.md).** This optional comparison is scoped to the accepted stable-key boundary subset described in [`../design.md`](../design.md). It is a semantic settlement-to-visible-primary diagnostic, not an async UX or network-DAG qualification.

Each arm starts with A revealed and B in its accepted fallback. Native B receives one direct `AsyncResource` made from the manually controlled Promise during mount; React reads the equivalent Promise directly. A then switches to a second pending resource; the collector checks that A's accepted DOM node/text remain unchanged and that no A fallback appears. It installs a MutationObserver before settling B's resource, then records settlement to the first callback that observes B's matching keyed primary. This includes MutationObserver delivery delay and stops before paint. Both arms must produce the same final view and preserve A's element identity. The B child reads one resource and contains no Store reader, effect, numeric binding or collection region. Mutations are also watched for insertion of A's fallback and sampled A visibility changes.

Native authored TSX is compiled by Rust/OXC; React authored TSX is transformed by Vite's React Compiler. The build proof checks Native component, Suspense-site, Store/resource lowering and React Compiler memo output. The page and collector use source-locked production assets through offline exact-manifest interception, synthetic HTTPS `.localhost`, headless Chromium, GPU disabled, 1200×900, a hard 90-second interruptible deadline, no focus stealing, no server, and no TLS connection. Unmanifested or external requests are blocked. Portless and trust-store operations are outside this diagnostic.

One manually controlled Promise settlement per arm is recorded, with no warmups, sample filtering, retries or p95. A bounded timer-quantum probe runs outside the timed interval. Timing begins immediately before B's resolve call and ends in the first matching MutationObserver callback. It includes observer delivery delay and excludes request discovery, network, human input and paint. Mount and teardown are separate observations. The sample can show whether the supported reveal contract completed and give two bounded intervals; it cannot replace the historical async DAG, equal-network preloading, urgent-input/fallback UX, heap/GC, cold-mount, second-device or visual/paint evidence.
