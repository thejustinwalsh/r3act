# Retained prop transaction slice

The replaced mechanism is whole-root publication-version rejection for a candidate that only changes retained primitive prop writers. Whole-tree/cache candidates keep their original version checks. Structure, cache and resource/reveal deltas remain later work.

The invariant authority remains World cell capabilities and versions, the compiler module revision registry, mounted VDOM source-to-writer indexes, and the existing candidate/group publication lifecycle. A prepared delta contains immutable inputs and outputs; each mounted writer's accepted-history generation detects overlapping accepted cuts. There is no separate source-version or conflict registry.

`ComponentStateRoot.prepareRetained(cells)` selects writers reached by the explicitly supplied committed numeric cells. Every source of a selected expression must be included, including controlling and unchanged joint inputs; missing coverage declines preparation. `OwnerStateWorld.cellHandle(owner, site)` exposes the existing committed capability without dispatching an artificial update. `NativeRootWorkQueue.enqueueRetained` names the roots/cells that publish together and uses the existing pending gates and publication queue. This is a low-level explicit transaction API; automatic transaction discovery is not promised.

The Rust/OXC compiler emits finite closed expression data alongside its existing projectors, from the same parsed expression and source references. The binding runtime installs validated, frozen expression data as the executable semantics of a closed numeric binding for both ordinary rendering and retained preparation. Its private immutable binding capability checks callback and source-array identities. Copied public descriptor metadata cannot grant that capability; the authored projector is never called by a closed binding. Arbitrary function-shaped metadata is not purity evidence. Unsupported expressions, aggregate/retained objects, unbound cells and incomplete input coverage decline this path; ordinary reconciliation remains available through the existing full-tree API. Retained transaction admission does not silently broaden into whole-tree reconciliation.

Before host application, a cut validates exact cell incarnations, World versions, values, owner/code lifetime, structure, canonical writer membership and accepted writer generations. Independent retained publications can intervene. Root logical publication versions advance on accepted deltas; VDOM structural versions keep their existing meaning. Full-tree work remains conservative. During host application, later same-cell actions stay pending, accepted writer history is staged, and destructive disposal is deferred. A group applies all hosts, validates all members, prepares all publication records and accepts all members before callbacks. Arbitrary partial host writes remain quarantined and are not rolled back; no cross-renderer paint atomicity is claimed.

The measured performance budget is unresolved. This slice preserves existing traversal layouts and historical evidence and makes no speed claim. Its correctness falsifiers include a stale input/code/owner reaching a writer, an unrelated prop delta being rejected only because root publication advanced, accepted history changing after partial failure, or acknowledgement consuming a newer action. Consolidated gate results are recorded separately. Cold setup, allocation, retained memory, a matched timing comparison and independent-device qualification remain open.
