# Integration review

The source finding is cross-root application reentry through one shared VDOMHost. Existing root-local barriers and each queue's own committing-root Set do not serialize another root or queue instance. The immutable baseline captures committed source independently of concurrent edits and asserts the old defect, without attributing performance cost.

One WeakMap keyed by exact host identity is the new admission and domain-failure authority. Existing private candidate receipts carry group claims. Public candidate methods and root options do not gain a partition, claim-token or purity API. Whole-tree and source freshness guards remain necessary. Root-local barriers still own their lifecycle and accepted-pointer phases; the host claim prevents a different root from entering physical application concurrently.

Primary review rejected a global sorted domain sequence and issued-token WeakSet: synchronous callback-free all-or-none admission requires neither lock ordering nor a parallel token identity registry. Wakes use separate microtasks so an exception in one caller scheduler cannot skip another queued wake. Domain quarantine preserves the first failure.

The generic queue's admission seam belongs after public validation and before committing flags/host work. A busy-domain signal uses existing pending-wave machinery, releases private preparations and retries after availability; it must not enter partial-failure handling. Native groups share one claim across same-host candidates and hold all domains through accepted publication. Availability subscriptions must close the failed-claim/subscribe gap and be removed on cancellation or disposal.

The new compiled regression uses actual Rust/OXC identities and semantic revision registration, followed by actual Vite OXC TSX emission. It must preserve raw authored/transformed/emitted/result/error artifacts. Installed Node controls exercise public package exports separately from the unchanged browser comparison.

Verification is pending. No timing or correctness conclusion follows from this review alone. The completed results file must record actual gate failures, source locks, installed controls and the sole bounded matched comparison, including limitations.
