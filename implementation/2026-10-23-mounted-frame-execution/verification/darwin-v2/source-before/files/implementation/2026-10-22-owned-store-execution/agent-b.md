# Passive World and Store capture handoff

Owned files: `src/owner_state_world.ts`, `src/async_store_runtime.ts`, and their corresponding tests. No owned-record, Root, compiler, VDOM, host, or publication source was changed. Tests were authored but not executed, per the integrated-slice cadence.

## Replaced mechanisms and authority

The passive route replaces Root's separate public World cell/lineage calls and the selected readers' public `readClosedProjections` calls. The existing World owner/cell maps, committed cell capability and `ScalarSource` remain identity/version authority. The existing Store action log, root epochs, transaction snapshot/readers/pending/observation maps, savepoint journal and accepted reader history remain the only Store authority. Legacy public calls retain their own fresh audits and observable order.

`captureOwnedClosedWorldInputs` returns aligned owner, lineage, handle, source, version and finite value rows. It copies all caller request and site containers first. The canonical static method requires a module-private key before touching the receiver or requests, then private-brand checks the World before reflection; a direct deep import cannot supply an unnormalized caller container to the static method. Exact prototype and descriptors of the replaced public methods are required. It reads only private committed owners/cells. Lane-backed or accessor-valued cells decline because the current numeric lane cannot be read through the passive data-property route. A source must yield its own canonical numeric data value equal to the cell's own value. Runtime-created handles preserve the existing cell identity.

`readOwnedClosedProjectionBatch` returns aligned numeric projection arrays. It copies all request descriptors before the transaction's private-brand check and Store audits. It requires an empty transaction, empty transition options, exact captured root/options fields and branded owned paths. It rejects transaction subclass/Proxy/read overrides. The operation checks the shared `AsyncStore.prototype` once and checks a Store's private brand, exact prototype and own overrides only on first insertion into the distinct-Store set. Repeated readers still undergo reader/path checks without repeating the instance audit. Its private cut helper shares log projection with `_beginClosedProjectionRender`. A batch-local Store/path-identity map traverses each branded projection plan once per distinct Store before any root interest or transaction reader is staged. The same arrays then seed the existing transaction-local projection memo. Each distinct Store is pinned once, while every reader retains independent membership, direct history and whole-state observation. No map survives the candidate transaction.

## Last callback to return

The last possible external trap is in the wrapper's final `Object.getOwnPropertyDescriptor(request, "paths")`. All request objects have been copied at that point. The captured canonical transaction method reads private fields, checks own root/options data descriptors, checks the canonical transaction read descriptor, audits the shared Store prototype, then invokes the key-guarded private-brand instance audit once per distinct Store. The remaining graph is `AsyncStore._captureOwnedBatchState` → `#closedProjectionState` over private log/root maps → batch-local Store/path-identity memo and `captureOwnedClosedProjectionValues` over branded paths and `storeRecord`-owned records → `_pinOwnedBatchRoot` → `StoreRenderSnapshot` constructor → seeding the existing transaction-local projection memo → per-reader snapshot/readers/pending/observation maps and existing journal helpers → frozen result. It invokes no public `beginRender`, `readClosedProjections`, selector, reducer, resource, World, or caller callback. The key-guarded methods return no reusable integrity permit.

World's last possible request trap is the final site descriptor copy. The wrapper passes its module-private key to the captured canonical World method; a direct call with any other key returns before reading requests. The method then private-brand checks before reflecting on the receiver, verifies exact prototype/method descriptors, and follows private owner/cell maps. Handle creation uses the existing committed-cell capability. No caller-shaped handle is read within that segment.

## Lifetime, fallback and falsifier

The arrays and rows are candidate-local. The transaction's private maps own its snapshots and reader staging until accepted publication or discard. The World result owns only immutable handles and primitive cuts; no new registry exists. Unsupported receivers, paths, state, transitions, accessor/lane cells, earlier transaction observations and overridden methods return `null`, so Root must use its original-order conservative route for the whole selection. Before a null Store result, no reader interest is staged. Existing checkpoint rollback, discard, accepted reader publication and exact receipt cleanup remain authoritative after a successful batch. This operation does not authorize later publication or eliminate later validation audits.

The required consolidated gate should include `deno test --frozen src/async_store_runtime_test.ts src/owner_state_world_test.ts`, then the primary's full correctness and installed proof. A failing adversarial override, reader-history, rollback or later-publication case falsifies passive-route eligibility. No speed or one-audit-per-frame claim is made.
