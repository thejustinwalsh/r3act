`codegenReactiveScope` emits a cache-slot `!==` check for each retained dependency, stores dependency and output slots on recomputation, and loads cached outputs otherwise; a dependency-free scope uses the `react.memo_cache_sentinel` on first render ([installed dist:90647–90765, 90863–90897](../2026-10-22-native-frame-publication/proof-canvas-v3/inputs/installed-store/babel-plugin-react-compiler@1.0.0/node_modules/babel-plugin-react-compiler/dist/index.js#L90647-L90897)). `codegenFunction` requests the exact slot count through an imported `react/compiler-runtime` hook ([90289–90302](../2026-10-22-native-frame-publication/proof-canvas-v3/inputs/installed-store/babel-plugin-react-compiler@1.0.0/node_modules/babel-plugin-react-compiler/dist/index.js#L90289-L90302)). React's runtime export `c(size)` delegates to the reconciler hook dispatcher `useMemoCache(size)` ([React production runtime:11–16](../2026-10-22-native-frame-publication/proof-canvas-v3/inputs/installed-store/react@19.3.0/node_modules/react/cjs/react-compiler-runtime.production.js#L11-L16)). This is a per-rendering-fiber cache, not a module-wide pool: the archived reconciler reads the work-in-progress function component's queue, copies the current alternate's cache arrays when necessary, initializes missing slots with the sentinel, advances a per-render call index and returns that call's array ([production reconciler:2940–2973](../2026-10-22-native-frame-publication/proof-canvas-v3/inputs/installed-store/react-reconciler@0.34.0_react@19.3.0/node_modules/react-reconciler/cjs/react-reconciler.production.js#L2940-L2973)). Its render path resets the work-in-progress queue; rerender-in-render resets the memo index ([2755–2773, 2802–2820](../2026-10-22-native-frame-publication/proof-canvas-v3/inputs/installed-store/react-reconciler@0.34.0_react@19.3.0/node_modules/react-reconciler/cjs/react-reconciler.production.js#L2755-L2820)). The alternate-cache copy preserves committed values across an in-progress render; it is not a shared array or cross-instance common-subexpression table.

The emitted transform is the decisive specialization for this authored program ([capture-react.json](../2026-10-22-native-frame-publication/proof-canvas-v3/capture-react.json), CompileSuccess for `Position`, `Rotation`, `FrameMarker`, `App`). Each motion component gets `_c(8)`: slots 0–2 cache the `id`-dependent layout-effect closure and deps, slots 3–6 guard `children` and the three calculated scalar values, and slot 7 holds the returned group element ([transform:30–116](../2026-10-22-native-frame-publication/proof-canvas-v3/transforms/react/react.tsx.js#L30-L116)). The scalar arithmetic stays outside the JSX memo guard, so every subscribed motion leaf still computes all three expressions after the new clock snapshot; the group element is recreated when any value or `children` changes. Dependency granularity here is scalar output values plus `children`, not the whole `frame` object, and not individual `frame.phase` subscription. A new snapshot with equal final scalars can still schedule the leaf via `useSyncExternalStore`, but its JSX cache may return the prior element. The compiler does not avoid listener fan-out or hook execution.

`FrameMarker` uses `_c(2)` with an `epoch` equality guard and one cached marker element ([transform:118–132](../2026-10-22-native-frame-publication/proof-canvas-v3/transforms/react/react.tsx.js#L118-L132)). `App` uses two dependency-free sentinel slots to retain the marker element and the complete static `Array.from(256)` authored tree ([134–181](../2026-10-22-native-frame-publication/proof-canvas-v3/transforms/react/react.tsx.js#L134-L181)). Yet `App` is not a clock subscriber ([authored react.tsx:18–44](../2026-10-22-native-frame-publication/consumer/react.tsx#L18-L44)); normal clock frames would omit its component body even without Compiler. Thus `_c(2)` is real emitted caching but is **not a demonstrated cause** of its ordinary-frame speed. The parent tree makes each `children` reference stable; the leaf `_c(8)` retains it. The authored `[id]` layout-effect dependency would suppress effect reruns without Compiler, even though Compiler also caches its closure/deps. No emitted cache is shared between the 256 motion component instances.

React's runtime reconciler independently delivers child-lane bailouts for unchanged ancestors and child subtrees; it is not generated by the Compiler ([production reconciler:5383–5417, 5539–5555](../2026-10-22-native-frame-publication/proof-canvas-v3/inputs/installed-store/react-reconciler@0.34.0_react@19.3.0/node_modules/react-reconciler/cjs/react-reconciler.production.js#L5383-L5555)). The installed R3F host still diffs and applies changing props ([R3F reconciler:641–678](../2026-10-22-native-frame-publication/source-basis/r3f-v10/reconciler.tsx#L641-L678)). Compiler output neither fuses the three arithmetic expressions into one host write nor bypasses R3F's commit path. Native also retains static children/resources; these shared omissions do not explain its timing deficit. No claim about V8 inline-cache quality, shapes or deoptimization follows without a JIT trace.
