# Packet A source handoff

The verified numeric Store branch now sends its reused dense output scratch directly to `OwnedScalarFrame.captureVerifiedNumericResults`. The frame module creates one final private values array, captures each required own result slot, requires each mapped result to be a finite number, checks exact literals with `Object.is`, and freezes it. Nonnumeric constant slots retain their primitive values. The layout's existing unused slot array stores the registration-time prop-to-result mapping when the verified proof is present. Numeric literals occupy result slots; nonnumeric literals do not. Two-argument layout creation and public `OwnedScalarFrame.create` retain their prior meanings and defensive copy.

Deleted from the verified branch: the complete intermediate `props` array and per-prop `defineProperty` fill, its traversal through host expressions, and the second `OwnedScalarFrame.create` transfer/copy. The interpreted branch still builds and copies ordinary props. Existing input and output scratch arrays, the final frame array, layout, proof kernel, row histories, mounted images, outer request normalization and public adapters remain. No scratch array is retained by a frame. Shared output scratch may be wider than a later row; capture validates and copies only the mapping's dense prefix without trimming it.

The retained graph is `ExecutionFacts -> OwnedScalarLayout` and verified proof, then `OwnedClosedStoreOutputRow -> OwnedScalarFrame -> layout + frozen private values`. No frame points to input/output scratch, the preceding frame, a builder or a callback. Layout adds one immutable verified flag and numeric-result count beside its repurposed immutable slots; no registry or mutable owner state is added. Optional `directCaptures` increments only after authentic direct frame construction, alongside the existing `frames` increment. Cold mapping validation and capture checks have unmeasured costs.

Focused source tests cover 1/32 values, mixed numeric and nonnumeric literals, signed zero, malformed maps, missing/nonfinite/nonnumeric results, exact constant rejection, own accessor/Proxy capture, brand forgery, retained old frames after scratch reuse, and alternating wide/narrow verified rows. These tests have not been executed by this packet. The consolidated gate should run the two edited Deno test files, the existing scalar proof and Store-progress suites, actual compiled fixtures and package checks. The installed proof must observe direct captures on 257 warm rows with ordinary materialization still zero, then positive materialization on explicit observation. This packet makes no timing or parity claim; the preceding Native 2.50/3.30 ms update and 5.10/6.60 ms through-draw remain slower than declarative React 0.95/1.30 and 4.25/6.60, and the copies' time share is unknown.
