The per-frame proof records group commitment, draw count and accepted root versions. Terminal batch/sweep counts follow an explicit epoch-73 direct flush, so they cannot certify exact per-frame public-route counts. Availability of emitted batch kernels is not a runtime frequency measurement. No extra counters will be inserted into frozen product code for this research.
