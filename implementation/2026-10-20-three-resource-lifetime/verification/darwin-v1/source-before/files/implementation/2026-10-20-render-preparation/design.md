The master plan requires an honest opaque boundary, not an inferred React-style purity rule. Add `renderPreparation: "repeatable"` as a caller declaration on existing root options and explicit generic preparation/work options. This permits generic render work to run before host application, be discarded, suspend and repeat. It is not compiler proof, not permission to skip owners or infer closed dependencies, and not rollback of escaped body effects. Store this immutable capability in existing root/work records, without a parallel version or identity registry.
