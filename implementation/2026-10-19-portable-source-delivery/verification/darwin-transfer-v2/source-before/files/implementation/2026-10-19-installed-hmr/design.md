The replaced mechanism is an ambiguous plugin chain that could classify one TSX module both as native and as React Refresh input. The public `nativeReactPlugins` composition owns source-derived membership before React plugin construction. The native plugin and semantic-plan registry retain revision authority; the application owns root and borrowed-resource lifetimes. This fixture adds no identity, accepted-view or version registry.

The contract is conservative. A native module revision invalidates its old plan and may remount through a Vite full reload. Before remount, the app disposes the native work queue, DOM and Three roots, React island and caller-owned borrowed geometry/material. The receipt must show zero old owners, pending changes, Three resources and event registrations, balanced React body lifetimes, and no stale pending reveal. A pure React panel edit should update via React Refresh, preserve its local counter and leave the native roots and Three object count intact. A file changing native classification requires the integration plugin to restart Vite and reconstruct the filters.
