## Implemented contract

If A's onSettled enqueues C with that key, C is newer and cancels B; outer B returns a cancelled handle without capture/provider startup. Independent operations still coexist across the same roots when their explicit keys differ. This retires the old claim-after-callback order rather than introducing a new key/order/version registry.

Task cancellation now reads the lower queue's existing exact WorkRecord.committing flag through a read-only internal delegate. An applying group finishes; task generation/lifetimes do not revoke its post-host validation. The same WorkRecord stays in its existing map through afterCommit, then retires before final onSettled; IDs remain active through finishing publication callbacks. Queue disposal marks disposed immediately and defers one destructive pass to a microtask when its own operation is applying. Existing disposed state prevents duplicate scheduling. The tests demonstrate subsequent fresh publication on the root rather than accepting a hidden quarantine.

Live selectors, subscription/provider setup and buildTree may replace/cancel the current operation. Terminal checks stop installation of staged roots/executions/native work, and release local transactions/interests. Provider return is checked before inserting the execution into the operation's owned Set. A private interruption error separates this control path from real caller errors; selector replacement followed by an authored exception preserves that exact exception and surviving C. Cleanup errors aggregate rather than masking originals. A typed reread of canonical mutable operation status handles TypeScript's callback-insensitive narrowing; no unchecked status cast or duplicate state is used.

Existing whole-tree/VDOM guards, per-root accepted history, exact captured acknowledgements, newer actions, writer/resource lifetime and failed-partial host quarantine remain. Cancelling publication does not roll back dispatched Store actions or arbitrary external provider effects. There is no cross-renderer visual-atomicity or arbitrary host rollback claim.
