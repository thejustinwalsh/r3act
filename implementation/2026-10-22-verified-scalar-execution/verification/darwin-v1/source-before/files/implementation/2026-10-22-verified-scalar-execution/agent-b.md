# Sol B handoff: finite source proof

Added `src/closed_scalar_kernel_proof.ts` and focused `src/closed_scalar_kernel_proof_test.ts`. No tests, build, benchmark, browser, server or VM were run by this agent.

The verifier checks the host module's private normalized-program WeakSet before reading expressions. Schema 5 is admitted only for an empty-child group; its nonnumeric literal props are omitted from dense numeric outputs while original prop positions remain in the frozen mapping. It obtains the candidate's complete actual source through captured `Function.prototype.toString` and captured `Reflect.apply`; it never reads candidate properties or invokes it. A function with native, bound, proxy or revoked source fails the finite parser. Successful proof retains the original callable and frozen dense numeric host-prop positions. A rejection returns one bounded static code.

Accepted wrappers are ordinary `function` with optional name or two-parameter arrow functions. Both require two distinct simple ASCII identifiers in parentheses. A block permits an optional exact `"use strict"` or `'use strict'` directive, `const`/`let`/`var` declaration lists with distinct single-assignment declarators and only prior aliases, and ordered `outputs[0] = ...` through the final numeric slot. Output assignments may be comma-separated within one block statement or separated by semicolons; the final statement may omit `;`. Arrow expression bodies accept one bare output assignment or a parenthesized comma sequence of ordered assignments. Arithmetic values never contain comma expressions. Arithmetic permits finite decimal/hex/binary/octal number literals, literal `inputs[n]`, prior local aliases, grouping, unary `+ - ~`, and binary `+ - * / % ** << >> >>> | ^ &` with JavaScript precedence and associativity. Whitespace and comments are ignored. Every token must be consumed.

The parser declines unsupported constructs, including output reads, dynamic indexing, calls, member properties, free identifiers, reassignment, forward locals, control flow and trailing tokens. Bounds are source bytes 32,768, tokens 16,384, symbolic nodes 8,192, locals 128, parse depth 128 and input/output slots 32. Host and source share an exact structural DAG interner. Child node IDs, operator, literal value and signed zero define each node; matching IDs prove structural equality without hash-only comparison or expanded local substitution. Numeric literal spelling and unary signed literal spelling normalize to the same number; arithmetic grouping and operand order remain distinct. Legacy leading-zero decimal spellings decline because sloppy-mode octal semantics differ. Intermediate nonfinite arithmetic is allowed because only literal finiteness is checked here; runtime retains final finite checks.

This is a source-based no-external-observation proof under the existing unmodified/captured-intrinsics premise. The accepted body can read only private own dense numeric input elements and assign ordered own output elements. It has no syntax for calls, external names, `this`, `arguments`, dynamic properties or buffer escape. The runtime must fulfill its assigned private-buffer and captured-apply obligations; this module does not enforce them.

The test file covers compact/renamed and ordinary forms, signed zero, grouping, overflow followed by bitwise coercion, property getters, forged hosts, native/bound/proxy/revoked callables, effects, hidden reads, alias misuse, output order and source/local/depth limits. The primary's compact-form review added positive controls for multi-declarator SSA, comma-separated block outputs and a bare one-assignment arrow, and negative controls for free calls in either list, duplicate `var` aliases, comma arithmetic values and named-function self-reference. The optional function name is never entered into the allowed value environment; only parameter and prior local names resolve. Full token consumption and exact ordered output count still close each form.

The lexer now stops at all four ECMAScript line terminators and resumes tokenization there. Hostile actual-function fixtures place a free call after each terminator and must decline without invocation; innocent comment fixtures remain accepted. A source review of the remaining lexer and ASI boundaries found that unsupported ASI-separated statements decline because the block parser requires `;` or `}` after each accepted statement.
