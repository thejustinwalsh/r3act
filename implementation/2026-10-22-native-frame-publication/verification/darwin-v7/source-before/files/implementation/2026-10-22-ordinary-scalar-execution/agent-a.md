# Sol A — World scalar cell cut

Owned files: `src/owner_state_world.ts`, `src/owner_state_world_test.ts`. No Store receipt batch, layout expansion, public barrel or production Root edit.

The new module exports `ClosedWorldCellCut`, `createClosedWorldCellCut(rows: readonly OwnedClosedWorldInputCell[]): ClosedWorldCellCut | null`, and `validateClosedWorldCellCut(world, cut, phase: "prepared" | "after-host"): boolean`. Rows are flat runtime captures with `{handle, source, version, value}`. The factory copies the array, every row and each handle through own data descriptors before any private validation. Equal duplicate captures of one owner/site collapse once within the cut; a different identity, source, version or `Object.is` value declines. The opaque object privately owns its normalized fields. It is candidate-local and should be released with that candidate; no World-global cache or second history was added.

The private validator checks genuine World and cut brands, current owner/staged status, exact committed capability and cell membership, source identity, passive own boxed numeric cell value, passive branded scalar source value, and version/value in one loop. `prepared` requires the exact captured version and `Object.is` value. `after-host` allows a newer version, while equal version still requires the captured value. Root must keep the old acknowledgement cutoff when a newer action occurs. Numeric lanes and accessor-backed cell/source values decline. `NaN` and signed zero use `Object.is`; the pre-existing passive capture may still select a narrower finite subset. Public World APIs and subclass callbacks remain available for the existing public validation phases.

The last external callback can occur during Root's public validation or host writer. Root should then invoke this private validator only with a prebuilt cut. Its call graph is `validateClosedWorldCellCut` → captured static World method → private capability/current-cell resolution plus passive own-value checks. It does not read the caller's row, array or handle, call public World methods, or invoke source accessors. Source proof first checks the runtime's private scalar brand; a Proxy cannot pass it. Any uncertain cell/source/lane fails before host work in the prepared phase, and again after host callbacks in the final phase. The replacement target in Root is the pair of canonical `scalarSourceForCell` and `versionForCell` calls in each private retained-cell validation; this file does not remove Root's old calls itself.

Authored regressions cover copied handles after caller mutation, forged/Proxy receivers and handles, later normalization destroying an earlier cell, same-key reincarnation, equal-version source changes including signed zero, newer host-time action, source accessor refusal, conflicting duplicate captures, NaN and lane refusal. They are unexecuted by design. Luna can run `deno test --frozen src/owner_state_world_test.ts` as part of the consolidated gate, then the repository's broader frozen runtime gate. Primary should review Root's public callback order and confirm the new validator replaces, rather than supplements, its old private lookup pass.

Cost claim: one copied candidate cut and one private cell resolution per check replace two private source/version lookups per cell only after Root integration. Allocation and elapsed savings are unmeasured. The falsifier is any caller callback during the final private check, stale cell admission, missing public validation, or retention of both old and new private passes on the successful route.
