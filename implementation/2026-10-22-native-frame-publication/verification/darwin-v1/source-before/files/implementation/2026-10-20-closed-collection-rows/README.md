# Closed collection rows

Read [design](design.md) and [verification protocol](protocol.md) before execution. The compiler emits one finite row template; runtime preparation materializes it without replaying mapper/row bodies and publishes through existing scoped keyed deltas. Only numeric paths through existing `storeRecord`-owned records qualify; opaque/unowned rows retain generic rendering.

The installed consumer preserves the previous complete async application for untimed regression and public host controls. Separate `closed_rows_native.tsx` / `closed_rows_react.tsx` entries exercise the changed collection path. `prepare.mjs` installs five fresh tarballs, checks types and controls, captures real compiler output and locks every selected source/package/asset. `verify-browser.mjs --phase proof` runs the complete async episode only; `verify-rows.mjs --phase proof|timing` runs the new episode. Timing requires an exclusive primary authorization bound to successful untimed proofs.

The full product finish line remains in the master guide. This slice does not change physical traversal layouts or certify speed, cold/memory, other platforms, independent hardware, paint atomicity or maintenance superiority. Historical evidence and failures retain their source scope.
