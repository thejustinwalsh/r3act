## Retired work and unchanged authority

For the eligible ordered passive rows, Root now calls `prepareOwnedClosedStoreOutputs(world, stores, requests)` once. It no longer makes a separate `captureOwnedClosedWorldInputs` plus `readOwnedClosedProjectionBatch` for those rows, builds a per-owner flattened `values` array, calls the public `evaluateClosedStoreDataExecution` on that array, or sends the resulting tuple list through the public scalar-region normalizer. Scoped host keys and owner-qualified retained children remain as before. Root counts `store.owned-data.enclosed-batches` only after all enclosed rows stage successfully.

VDOM no longer owns a second scalar-region WeakSet or normalizer. Its exported constructor delegates to `closed_store_execution.ts`, and admission asks that module's ownership query. VDOM's mounted keys/buckets, target records, prior accepted values, journal, writer, publication token and post-write checks remain authoritative. An owned region is immutable data, not an admission permit.

All cache props assignments were audited: main expansion copies node props into a fresh object, reveal copies descriptors into a fresh object, Suspense spreads props into a fresh object, and subsequent cache sets copy existing cache references.
