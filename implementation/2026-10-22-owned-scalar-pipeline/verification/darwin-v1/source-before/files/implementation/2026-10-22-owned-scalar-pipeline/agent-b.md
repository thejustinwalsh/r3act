# Sol B handoff — enclosed owned scalar outputs

`src/closed_store_execution.ts` now binds immutable input paths, state sites, arity and retained-child shape to the existing privately normalized execution association. `prepareOwnedClosedStoreOutputs` normalizes every request and nested input first, captures World rows, then invokes the existing Store projection batch once. It fills one bounded local numeric scratch for each row, uses the existing finite evaluator, and constructs each frozen output pair and region once. `region.props` is the final tuple list for Root and VDOM. The scratch array is never returned or retained; only primitive outputs and existing frozen World lineage/cells escape.

The scalar-region WeakSet and complete caller-facing normalizer moved from VDOM into this module. `isOwnedScalarStorePropDelta` queries that one authority. The public normalizer still copies arbitrary descriptor-backed caller data, validates host values and preserves empty explicit children. The private batch constructor uses only the associated normalized program and finite evaluated primitives. The only VDOM import here is `import type { StorePropDelta }`.

The exact API is `OwnedClosedStoreOutputRequest`, `OwnedClosedStoreOutputRow`, `prepareOwnedClosedStoreOutputs(world, transaction, orderedRequests)`, `isOwnedScalarStorePropDelta` and `createOwnedScalarStorePropDelta`. A ready result carries `{kind:"ready",rows}`. World or Store passive capture decline returns `{kind:"public-required"}` only before Store pin/observations. All request normalization, evaluation and exception failures return `null` and require candidate discard. A tightened Store wrapper now confines caught TypeErrors to its pre-capture request copying; private-call exceptions propagate and B maps them to `null`. Root's privately built requests contain no normalization callbacks. A public deep caller must discard an unsuccessful preparation because arbitrary normalization callbacks have no rollback promise.

This replaces Root's separate World/Store capture, per-owner flattened `values`, public evaluator descriptor copy and VDOM's second output tuple/region normalization on the successful passive route. Existing World identity, Store transaction/history, Root lifecycle and VDOM journal/host writer remain the authorities. Semantic obligations include ordered readers, signed zero, finite output, retained children, exact old-cut acknowledgement and conservative fallback. The measured budget remains unknown; the prior fixed-order comparison still loses. Falsifiers include a second tuple copy, changed callback order, a ready row with scratch aliasing, or a post-pin failure routed to public fallback.

Authored regressions in `src/closed_store_execution_test.ts` cover alternating programs, input order, independent readers sharing one Store, schema 5/6/7 retained regions and legacy key regions, signed zero, late normalization mutation, forged provenance, pre-pin public decline, overflow and output lifetime. No tests or benchmarks were run by Sol B. Luna can include `deno test --frozen src/closed_store_execution_test.ts` in the consolidated correctness gate after primary reviews the integrated slice.
