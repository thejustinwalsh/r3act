# Urgent retained prop: one descriptive event-to-DOM pair

Status: **ONE DESCRIPTIVE PAIR COMPLETE.** The single authorized offline headless pair measured 1.6 ms Native and 0.8 ms React from synthetic click dispatch to matching MutationObserver delivery. Timer resolution was 0.1 ms; this is one observation per arm and not a qualification result. Full details and limits are in [`../verification/gate-results.md`](../verification/gate-results.md). This workload checks a compiler-closed local prop update through the ordinary authored button path while unrelated Store/resource work remains pending. It is a narrow semantic/performance observation, not a product qualification.

Both arms mount A at its accepted primary and a button at `x = 1`. A then selects a pending resource. After two untimed animation frames, the collector verifies A's original node and text remain visible and no A fallback was inserted. One synthetic bubbling click is dispatched. The measured interval ends at the first matching `MutationObserver` callback where the same button node has `data-x="2"` and inline opacity `0.2`. The interval includes normal runtime scheduling and observer delivery and ends before paint. The text label remains constant.

The native authored TSX uses `useState(1)`, a state-derived `data-x`, a primitive `style.opacity={x / 10}` output, and `onClick={() => setX((n) => n + 1)}`. Its build proof must inspect actual Rust/OXC component/state/closed-output metadata and the React arm's actual React Compiler output. Both implementations use normal click handlers; the native event is an explicitly synthetic DOM event. A's pending-resource behavior is checked but excluded from the measured click.

The pair records each arm once. It includes separate mount/disposal observations, timer quantum, final text/defined prop digest, A/button identity, A visibility/fallback trace, teardown checks, source/build/artifact hashes, and exact asset sizes.
