# Integrated source review

The automatic path uses `prepareRetained` and its existing finite-expression, input coverage, source/owner/code/writer checks. It does not remove Store/resource guards from the weaker row/lane executors. Admission requires actual resource subscriptions or resource/boundary retry work, not merely a dirty Store generation; otherwise a fresh synchronous Store action could be skipped after a local-only publication. The new synchronous Store-plus-cell regression protects that distinction.

The initial candidate captures every native pending cell and requires complete program read coverage. Opaque, incomplete, aggregate or collection-bearing batches decline. The existing execution guard now covers scoped flush work rather than only boundary drains. Each later ready boundary is prepared fresh; newer input/resource/Store work remains pending. No persistent attempt-generation, source or conflict registry was added.

`#prepareCandidate` already acknowledges its own captured World/root cut during accepted publication before callbacks. Old post-generic `#finishChanges` calls redundantly cleared accepted cuts and also falsely cleared blocked cuts. They are retired from generic flush/update callers. Direct numeric/partial paths retain their acknowledgements. `#renderAndCommit` returns its own publication outcome for resource retry control, rather than inferring it from unrelated publication version changes.

Actual authored DOM and Three fixtures inspect real Rust/OXC registration/layout/closed expression output. Setters are installed by committed activation effects; no test control is overwritten by speculative component renders. The Three path exercises scalar `position-x` on a live Mesh with default shared fallback resources; it does not claim mutable vector, material or rendering qualification.

A separate confirmed next seam remains: direct `update(newTree)` discards unaccepted authored tree intent when preparation blocks, while later retry uses accepted `#tree`. The React migration adapter can encounter this. Explicit queued work already retains its desired tree and is a different path. Fixing direct intent must keep accepted tree separate, preserve dependency lifetime, define supersession with explicit queued replacements, and guard scoped publication; it is not permission to remove whole-tree checks. This slice does not conceal or claim to fix that gap.

The consolidated correctness gate passed 838 runtime tests and ten actual compiled fixtures; the sole matched synthetic click diagnostic passed correctness with 1.6/0.8 ms Native/React (Native slower). These verify only their frozen source and output contract. Dense physical selection, general Store/resource independence, cold/memory, paint and independent-device qualification remain open.
