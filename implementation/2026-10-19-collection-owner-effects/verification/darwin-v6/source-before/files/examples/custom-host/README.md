# Custom retained Canvas host

This example implements a third native host using the public `VDOMHost` contract from `@r3act/core`. Authored TSX drives a DOM root, a Three scene root, and a retained Canvas command graph through one World and Store. The Canvas host owns its node tree, event handlers, value writes, and brush lifetimes; it does not add a reconciler or a second publication/version authority.

The controller in `main.ts` exposes `window.customHostDemo` for inspection. Call `click("shared-a")`, `move()`, `removeSharedFirst()`, `removeSharedLast()`, `replaceOwnedBrush()`, and `publishB()` to exercise local state, keyed identity, owned/shared/borrowed resources, and a declared three-root Store publication. `snapshot()` returns DOM/Three accepted outputs, deterministic Canvas frame commands, resource counters, root diagnostics, Store diagnostics and post-publication subscriber observations. `lateClick()` targets the removed first shared row; `dispose()` is idempotent and checks the borrowed brush only after host teardown. The browser clears and repaints the Canvas after successful publication; that painting is an application observation of accepted host state, not a claim of cross-host visual atomicity.

`position` receives a fresh two-number tuple per authored render and the host copies it during a property write. Brush bindings also copy their wrapper, while `payload` retains caller object identity. The controller replaces its brush-props record when a binding changes; mutating an existing object in place is not a reactive update signal. `describePropertyWrite` reports current value and resource policies but does not certify callback purity, enable scoped admission, or make host setters infallible. Owned brushes dispose after their final binding; the caller retains borrowed brushes until its own explicit cleanup.

Run the installed consumer proof from the repository verification harness. It packages `@r3act/core`, `@r3act/host-dom`, `@r3act/host-three`, and `@r3act/vite` into a fresh project, typechecks/builds this example without checkout aliases, and checks an actual Rust/OXC compiled execution fixture.
