## Replaced mechanism and invariant authority

World's existing parent-owner/site/key tuple is the sole owner authority. Generic expansion currently carries the component parent unchanged through intrinsic hosts, so equal component site/key values under different host parents resolve to one owner. Traversal path cannot safely repair this: full render, partial structural render and Suspense retry use different path prefixes. Replace those unscoped lookups with one canonical structural scope while preserving World, module/site revisions, pending actions, root accepted histories, VDOM and publication authority. No second owner/version registry or host entity universe.

A transient immutable StructuralScope has an optional encoded parent scope and a local position. A host segment includes its tag and authored key, or its position relative to the nearest structural parent for unkeyed/generated-key hosts. Keyed parent moves keep the segment; type/key changes or positional movement of an unkeyed parent retire descendants. Component and Suspense owner boundaries reset local structural scope. Direct components with no structural parent retain their existing tuple. Raw authored component keys remain unchanged; the effective World site incorporates the structural scope through a length-safe encoded segment path.

A flat top-level array or one unkeyed top-level Fragment stays transparent. A nested array or unkeyed Fragment at a sibling-list position contributes a positional container segment; keyed Fragments always contribute a keyed segment. Preserve the current native per-component-site ordinal policy within one list; do not silently claim complete React reconciliation equivalence.

Generated host keys need creator provenance because carryHostKeys has already added keys before expansion. A private symbol in the existing runtime-owned intrinsic props records generated-key status. Canonical copies preserve it alongside the existing owner stamp; it is not a new mutable identity/version registry. Authored explicit host keys do not gain it, and it is not a host attribute or public authoring capability.

Keep authored compiler sites and hook meanings distinct from derived structural coordinates. No Rust semantic IR change is assumed. Pure forward chains and first Suspense reveal must agree with later generic expansion. Candidate discard, retry, code retirement, old accepted snapshots, exact acknowledgements, newer reentry, fork history, live writers and partial-host quarantine remain.
