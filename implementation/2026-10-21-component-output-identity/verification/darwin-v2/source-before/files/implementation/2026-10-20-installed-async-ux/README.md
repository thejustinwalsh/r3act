# Installed forked async UX slice

This unit evaluates the complete authored forked-transition interaction using five freshly installed `@r3act` packages and independent Native and React production graphs. [Design](design.md) fixes the semantic scope and evidence limits. [Protocol](protocol.md) defines source locking, untimed browser proof, the one authorized descriptive timing pair, cleanup, and failure retention.

`consumer/` contains the source-bound application and browser driver. `prepare.mjs` builds a new `proof-vN`; `verify-browser.mjs` consumes its immutable lock and build proof. Implementation agents edit source only. The primary reviews and releases the consolidated gate to Luna, then authorizes the one timing pair after untimed proof review. No project server or VM is needed.
