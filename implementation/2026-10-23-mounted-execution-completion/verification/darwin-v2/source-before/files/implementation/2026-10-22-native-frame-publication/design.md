# Native frame publication

Base 5672b56bc95c9fa0fd227efe37cc6dfed808de78. Master-plan realtime direction, dependency-scoped coherence and host/publication contracts select this integrated capability. The prior batch candidate is closed as a speed solution; no compiler, kernel, layout, selector or writer tuning is authorized here.

## Replacement and authority

Replace application-owned RAF/update/flush/hidden-marker readiness with a public frame controller over the existing NativeRootWorkQueue. Explicit root/Store participants define one frame publication group. Dependencies still select consumers; DOM roots excluded from that list retain their own cadence. Existing queue receipts, root publicationVersion, Store reader histories, owner/code/host lifetimes and exact acknowledgements remain the only semantic authorities. No parallel frame version, root acceptance, source history or host registry.

The finite scope is compiler-supported closed Store publication, including mixed local inputs and retained children. Unsupported scoped readers decline before drawing; do not fall back to speculative unknown component rendering. Generic UI work keeps ordinary root scheduling. A frame controller does not certify all pending work in a root or atomic paint across hosts. Arbitrary setters remain nonrollbackable. It owns callbacks, subscriptions and queue work, never caller roots/stores/renderers/resources.

## Frozen interface

New src/native_frame_loop.ts exports createNativeFrameLoop, NativeFrameTime, NativeFrameResult, NativeFrameLoopOptions, NativeFrameLoop. Native runtime API reexports them. Options: roots: NativeStoreRootWork["roots"]; update(frame: NativeFrameTime):void; draw(frame: NativeFrameTime):void; optional requestFrame(callback):number and cancelFrame(id):void as a pair; optional maxDeltaMs default50, positive finite; optional onError(error):void. NativeFrameTime is frozen {timeMs,deltaMs}. Controller starts paused and exposes start(), stop(), advance(timeMs), dispose(), running/disposed getters. advance manually performs at most one update/publication/draw cycle and returns NativeFrameResult with status drawn/pending/cancelled/stale/failed/disposed, frame timing and existing publication resolution where available. Manual advance needs no browser globals. Default RAF functions are resolved only on start. Decreasing/nonfinite timestamps reject before update. First tick after start has delta0; clamp long intervals. No catch-up loop or worker.

Use one owned queue. While one frame waits, advance refreshes that work rather than rerunning update or accumulating requests. A resource/host wake may finish publication outside RAF; draw waits until a later advance. Capture the owned queue’s committed participant versions at successful settlement (getVersion without resynchronizing to a later root); before drawing a delayed completion, compare current root versions and reprepare the same selected Store group if another root commit intervened. This is a short-lived receipt-derived validation, not a mutable version authority. Frame time describes the requested update, not a promise that external Store dispatch stopped. Never interpret root.flush boolean as frame completion. The driver must not infer completion from a hidden scene marker.

Stop/dispose cancel owned RAF and pending group work/release its holds; domain actions and roots stay caller-owned. Retired participant roots stop/dispose the controller and prevent later drawing. Reentrant advance rejects, including update/draw/host callbacks. Disposal during preparation/application prevents draw and uses existing deferred queue cleanup. Update/draw/scheduler exceptions stop scheduling, preserve original plus cleanup errors and are observable; a postpublication draw error does not roll back or poison an accepted root. A failed publication is latched; later advance returns that receipt and start rejects before update. No automatic retry after a failed host writer. At most one live scheduled callback; stale callbacks after stop/restart must not consume the replacement request or draw.
